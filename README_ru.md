### server.py
Многопоточный FTP-подобный файловый сервер с:
- Загрузкой/скачиванием любых типов файлов
- Навигацией по директориям (CD)
- Просмотром содержимого каталогов (LIST)
- Автоматическим определением локального IP
- Очисткой консоли для разных ОС
- Управлением клиентскими подключениями

Основные возможности:
- Использует TCP-сокеты на порту 5001
- Хранит файлы в директории "server_files"
- Поддерживает одновременные подключения
- Базовая обработка ошибок
- Журналирование подключений

### client.py
Клиент с расширенными возможностями:
- Интерактивный режим и работа через аргументы:
  - `-i IP` - IP сервера
  - `-p PORT` - Порт сервера
  - `-l` - Список файлов
  - `-u ФАЙЛ` - Загрузка файла
  - `-d ФАЙЛ` - Скачивание файла
  - `-h` - Справка
- Автоопределение локального IP
- Кроссплатформенная очистка экрана
- История сессий
- Подсказки команд
